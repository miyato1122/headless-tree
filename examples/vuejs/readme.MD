# Basic example of Headless Tree with Vue 3

To run this example:

- `npm install` to install dependencies
- `npm start` to start the dev server

You can run this sample from [Stackblitz](https://stackblitz.com/github/lukasbach/headless-tree/tree/main/examples/vuejs?preset=node&file=src/main.ts) or [CodeSandbox](https://codesandbox.io/p/devbox/github/lukasbach/headless-tree/tree/main/examples/vuejs?file=src/main.ts). The source code is available on [GitHub](https://github.com/lukasbach/headless-tree/tree/main/examples/vuejs).
